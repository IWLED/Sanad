# سند (Sanad) - السكرتير الشخصي الذكي (Personal AI Secretary)

سكرتير شخصي ذكي لمستخدم واحد، يعمل على خادم ذاتي الاستضافة، وواجهته تطبيق أندرويد خاص.
يجمع بصمت ما يصل إلى جوالك (مكالمات فائتة، SMS، إشعارات واتساب وتيليجرام وغيرها، بريد، تقويم)، ويلخّصه حسب الموضوع والأولوية، ويقترح ردوداً تُرسَل فقط بعد اعتمادك الصريح (Human-in-the-Loop).

## الهيكل العام للمشروع
* `docs/`: التوثيق الفني، سجل القرارات المعمارية (ADR)، سجل التقدم، ودليل التجارب الميدانية.
* `shared/`: بروتوكول الاتصال (JSON Schema)، ومتجهات الاختبار الموحدة بين البايثون وأندرويد.
* `server/`: خادم بايثون (FastAPI + Worker + SQLite WAL + LLM Agent + HITL Engine).
* `android/`: تطبيق أندرويد (Kotlin + Jetpack Compose + Background Sensors).
* `deploy/`: إعدادات النشر بـ Docker Compose والنفق الآمن (Cloudflare Tunnel).
