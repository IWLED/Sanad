# سجل مزودي الذكاء الاصطناعي وسياسات البيانات (docs/providers.md)
> تنفيذاً للقاعدة الأمنية `R-19`: يُشترط أن يضمن المزود عدم تدريب نماذجه على بيانات المستخدم الشخصية، ويُمنع استخدام الطبقات المجانية غير المضمونة.

| المزود | الخدمة | النموذج / الغرض | شروط الخصوصية وعدم التدريب | حالة الاعتماد |
|---|---|---|---|---|
| OmniRoute (محلي على السيرفر المنزلي) | بوابة توجيه محليات وسحابية | وسيط داخلي (`http://192.168.100.28:20128/v1`) | يعمل ذاتياً داخل الشبكة المحلية، لا يحفظ المحتوى ولا يسربه. | معتمد |
| مزود LLM السحابي الأساسي (Profile: reasoner) | استدعاء أدوات وتحليل متقدم | يُحدّد بعد فحص التوافق S5 | حساب مدفوع Tier-1 مع تفعيل Zero Data Retention (ZDR). | قيد التقييم (Spike S5) |
| مزود LLM السحابي السريع (Profile: fast) | تلخيص الخيوط والتصنيف | JSON mode | حساب مدفوع مع شرط عدم التدريب. | قيد التقييم (Spike S5) |
| مزود STT (تحويل الصوت لنص) | تفريغ صوتي عربي خليجي | Whisper / Cohere Transcribe / Local | سيُحسم بناءً على نتائج التجربة الميدانية S4. | قيد التقييم (Spike S4) |
